# Agent 按项目名引用项目，不存在则自动创建

skill 发布时用 `--project <名字>` 指定项目（而非项目 ID），且**项目不存在时自动创建**。项目名在同一创建者内部唯一，不同创建者可重名。

理由：Agent 定时任务无人值守，脚本里写死一个语义化名字最自然；"先显式建项目再发布"会让每个 Agent 任务多一步状态维护。这是本功能服务 Agent 场景的核心语义。

**Consequences（已知隐患，有意接受）**：站长在管理页给项目改名后，仍用旧名发布的 Agent 会匹配不到、从而自动创建一个同名新项目，文章会"悄悄分流"。缓解措施是改名确认弹窗必须警告此后果，而非引入 ID 引用（脚本可读性差）或禁止改名（因噎废食）。
